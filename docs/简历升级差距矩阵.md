# 云仓智配简历升级差距矩阵

盘点日期：2026-09-29。依据当前源码、V1 OpenAPI、设计文档、正式 SQL、MySQL 真实环境验收报告、配置与现有测试。此表记录实施前基线，完成后按最终验收报告更新实际结论。

| 目标简历技术点 | 当前真实实现 | 已有证据 | 差距 | 是否值得实现 |
|---|---|---|---|---|
| 三量库存、入出库、调拨、盘点及 before/delta/after 流水 | 已实现，MySQL 为真实数据源 | 13 项 MySQL 8/InnoDB 专项，28 项完整回归 | 不需要改核心逻辑 | 已完成，保留 |
| 条件 UPDATE 原子预占，防并发超卖 | 已实现，检查 affected rows；同单状态机与行锁 | 真实 MySQL 同单、跨单双线程及直接 Mapper 竞争测试 | 不需要重复实现；不可声称测试过错误实现的具体窗口 | 已完成，保留准确表述 |
| 单据、库存、流水、预警统一事务 | 已实现；BusinessException 为 RuntimeException | 多 SKU 第三行失败整单回滚及预警回滚测试 | 不需要改核心事务 | 已完成，保留 |
| 动作型请求无重复库存副作用 | 状态机、FOR UPDATE、条件更新 | 重复 confirm/reserve/dispatch/receive 测试 | 不提供首次成功响应回放；简历须区分 | 已完成，保留准确表述 |
| 创建型请求级幂等 | 未实现，order_no 由服务端生成 | 无 | 需可选 Idempotency-Key、数据库唯一约束、并发重试测试与 V1.1 扩展说明 | 值得做：网络重试真实场景，保持 V1 兼容 |
| Redis 库存详情 Cache Aside | 默认关闭的单仓+SKU 缓存已实现 | 模拟 Redis 单测，未有真实 Redis/MySQL 联合测试 | 需真实 Redis 的命中、TTL、失效、旧读回填、故障回源测试 | 值得先验收；不扩大到仓库/SKU 基础资料 |
| Redis 空值缓存防穿透 | 未实现；不存在库存行返回零库存，但不缓存 | 单测证明不存在行不缓存 | 首次建行和 SKU 安全库存变更失效路径复杂 | 暂不做；简历不写空值缓存 |
| RabbitMQ 低库存通知 | 未接入；预警状态在 MySQL 事务内同步维护 | 无 MQ 证据 | 需真实通知中心、Broker、消费幂等和真实环境测试 | 仅在能建立真实 Broker 与可见通知闭环时做；否则不写 MQ |
| Publisher Confirm/Return、发送失败恢复 | 未实现 | 无 | 若要声称可靠发送，需最小 outbox、确认、不可路由与重试实测 | 与真实通知场景绑定；不单独为技术名词实现 |
| 消费失败及重复消息处理 | 未实现 | 无 | 需 eventId 唯一约束、重投/重启测试 | 若接入 MQ，则必须做 |

## 决策边界

1. 核心扣减继续依赖 MySQL 事务、行锁、条件更新和唯一约束。Redis 只加速查询，MQ 只允许承担非核心通知。
2. 可选请求头以 V1.1 扩展方式记录；不改变现有 50 个 V1 operation 的请求体、路径或无请求头时的行为。
3. 当前本机 MySQL 8.0.45 可用；Redis 3.2.100 程序已安装但服务未运行；本机未发现 RabbitMQ 服务或 Docker。真实环境测试结果必须注明实际版本与限制。
