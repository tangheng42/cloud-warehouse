# 云仓智配项目面试题（40 题）

标记说明：基础 / 中等 / 重点 / 高频追问。定位指项目源码中的类与方法；XML 语句可从对应 Mapper 方法追踪。建议先自己口述，再打开源码核对。

## 业务（1–4）

1. 【基础】实物量、可用量和锁定量分别是什么？三者关系为何必须成立？定位：`StockQueryService.get`、`StockMapper`。
2. 【重点】出库从创建到完成，每一步库存三量与流水类型怎样变化？定位：`OutboundService.reserve/release/confirm/cancel`。
3. 【重点】调拨发运后货物在哪里？为何目标仓不能在 dispatch 时加库存？定位：`TransferService.dispatch/receive`。
4. 【中等】低库存预警为何按 available 而非 physical 判断？安全库存更新时怎样处理已有库存行？定位：`StockAlertService.refresh/refreshSku`、`SkuService.update`。

## Spring（5–8）

5. 【基础】Controller、Service、Mapper 分别负责什么？DTO/VO 为什么与 Entity 分开？定位：`OutboundController.create`、`OutboundService.create`。
6. 【高频追问】`@Transactional` 标在 Service 动作方法上的意义是什么？自调用会有什么风险？定位：`InboundService.confirm`。
7. 【中等】JWT 生成、拦截器鉴权和角色限制如何连接？定位：`AuthController.login`、`AuthInterceptor.preHandle`、`RequireRoles`。
8. 【重点】事务提交后再删缓存是如何实现的？为什么不在事务中更新 Redis？定位：`RedisStockDetailCache.invalidateAfterCommit`。

## MyBatis（9–12）

9. 【基础】Mapper 接口与 XML 如何绑定？参数占位符和动态 SQL 用在哪里？定位：`StockMapper.reserve`、`StockMapper.xml`。
10. 【重点】订单分页先查单据头、再批量查明细，怎样避免 N+1 和 JOIN 破坏分页？定位：`InboundService.list`、`InboundMapper.findItemsByOrderIds`。
11. 【中等】MyBatis 更新行数为什么必须检查？0 行分别可能表示什么？定位：`OutboundService.reserve`、`StockMapper.reserve`。
12. 【高频追问】Mapper 的 `FOR UPDATE` 查询必须运行在什么事务边界内？定位：`TransferService.lock`、`TransferMapper.findForUpdate`。

## MySQL（13–16）

13. 【重点】`warehouse_stock` 为什么要有仓库加 SKU 唯一约束？首次库存行如何创建？定位：`StockMapper.inboundUpsert`。
14. 【中等】数据库 CHECK 约束与条件 UPDATE 各保护了什么？定位：`docs/sql/01-schema.sql`、`StockMapper.xml`。
15. 【高频追问】`stock_flow` 为什么不能对 bizId 加 flowType 唯一键？定位：`OutboundService.reserve/release`、`docs/sql/03-v1-business-schema.sql`。
16. 【中等】订单列表按状态和创建时间筛选时，如何分析复合索引左前缀？定位：`InboundMapper.list`、`docs/sql/03-v1-business-schema.sql`。

## 事务（17–20）

18. 【高频追问】库存更新成功、流水插入失败会怎样？哪些异常可能导致默认事务不回滚？定位：`InboundService.confirm`。
